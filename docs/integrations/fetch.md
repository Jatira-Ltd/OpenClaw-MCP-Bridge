# Fetch Integration

**Package:** `@kazuph/mcp-fetch`

## Environment Variables

None required.

## Available Tools (1 tool)

| Tool | Description |
|------|-------------|
| `imageFetch` | Fetch web pages with image extraction. Supports URL, text extraction, image fetching with base64 output. |

## Parameters

- `url` (required) - URL to fetch
- `text.maxLength` - Max text length
- `images` - Enable image fetching
- `enableFetchImages` - Legacy image flag
